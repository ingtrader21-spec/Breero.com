# DATA / FILE / RETENTION POLICY

Create configuration authority for:

```
abandoned ProjectRequests

messages

customer attachments

provider credentials

provider gallery

job evidence

dispute evidence

integration payloads

audit

payment records
```

For each:

```
classification

owner

access permissions

retention

deletion

legal hold

export

backup retention

log redaction
```

File-purpose matrix must define:

```
allowed MIME

extensions

maximum bytes

scan requirement

retention

download authorization
```

No globally hard-coded legal-retention assumptions.
